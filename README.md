## 🔥 核心卖点

1. **双引擎互为校验** — kill1 V8 条件决策树 + kill2 独立算术公式，两套逻辑独立运算，任一引擎误杀即不计数
2. **规律挖掘三件套** — 跨期切块组合挖掘（移植自 lottery-analyzer）：胆码（至少一位开出）/ 毒胆（全部不开）/ 和尾杀号 ×3，逐期滚动回测并如实对照随机基线
3. **每日自动更新** — 开奖后 22:00 / 23:30 / 次日 01:00 三重 cron 自动抓数、回测、发布，无需人工干预
4. **无未来信息** — 回测严格按期号回溯，输入仅上期开奖号 `(b, s, g)`，不含任何未来数据，数字可审计
5. **纯函数零依赖** — Go 单二进制，无数据库无运行时依赖，本地/云端/Docker 任意部署
6. **透明可自建** — 数据源、引擎、回测逻辑全部开源，运行日志内置表现监控（滚动 100 期 <70% 或单月下滑 ≥8pp 时终端告警）

## 🔎 规律挖掘（跨期组合参考）

移植自开源库 [lottery-analyzer](https://github.com/liangguifeng/lottery-analyzer)（MIT）的跨期规律路径挖掘引擎：

- **切块**：历史按期号切成「3 期规律区间 + 1 期验证期」的块
- **组合**：跨期取位置组合（如 `1_1|2_2|3_1` = 第 1 期百位 + 第 2 期十位 + 第 3 期百位），共 C(9,3)=84 种
- **连续命中**：前 3 块（从最新往旧）全部命中的组合才算稳定规律
- **五类分析器**：胆码（至少一位开出）/ 毒胆（全部不开）/ 杀百个·百十·十个和尾

页面逐期滚动回测（近 100 期 + 全量），**如实对照随机基线**——胆码/毒胆约 5 成、和尾约 9 成，不做任何夸大。规律明细（路径 + 最大连续命中块数）可展开审计。

## 🚀 快速开始

```bash
go build -o fc3d-kill6 .
./fc3d-kill6              # 抓数 → 追加CSV → 回测 → 生成index.html → 升级检测
go test ./...             # 引擎基准一致性测试
```

Docker 一条命令自托管：

```bash
docker build -t fc3d-kill6 .
docker run --rm -v $(pwd):/data fc3d-kill6 \
  -csv /data/fc3d-history.csv -html /data/index.html -kill6 /data/kill6_history.json
```
